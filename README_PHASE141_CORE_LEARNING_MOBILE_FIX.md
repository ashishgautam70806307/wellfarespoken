# Phase 141

Use this package as a cumulative replacement for Phase 140.

Phase 141 changes only the mobile presentation of Spoken Materials, Learning Roadmap, and Weekly Test. It adds one scoped stylesheet, compact mobile headings/status text, safe readable card layouts (including the 2+1 Weekly Test arrangement), and a v141 service-worker cache. No database or business logic changes were made.

After deployment, clear the old service worker/site cache and reload with Ctrl+F5.
