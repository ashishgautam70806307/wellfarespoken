# Phase 71 - One-time question read + repeat command

Changes:
- Question is read one time only.
- Spoken prompt includes question number + actual question sentence.
  Example: "Question number 4. वह आज व्यस्त है।"
- Student can ask to repeat by voice:
  - again bolo
  - dobara bolo
  - phir se bolo
  - repeat question
  - say again
  - nahi suna / sunai nahi diya
- Repeat commands do not count as wrong answers.
- System repeats same question + sentence and restarts mic.
- Normal answer checking continues after the student speaks the answer.
