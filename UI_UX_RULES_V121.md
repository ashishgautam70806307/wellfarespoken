# UI/UX Rules — V121

## Brand system

- Primary navy: `#03163f`
- Secondary navy: `#0a3476`
- Primary gold: `#dda91f`
- Success teal/green: used only for learning progress and correct answers
- White and soft grey surfaces keep learning content readable

## Typography hierarchy

- Home hero: 46–80px desktop, 36–52px phone
- Inner-page hero: 38–64px desktop, 30–38px phone
- Section heading: 32–52px desktop, 28–38px phone
- Card heading: 18–27px
- Body: 15–17px
- Form labels: 14px
- Supporting text: 12–14px only where secondary

## Component sizes

- Main buttons: minimum 46px height
- Small buttons: minimum 40px height
- Form fields: minimum 48px height
- Public cards: 220–300px content-dependent height, equalized inside grids
- Dashboard stats: consistent 126–150px height
- Mobile bottom navigation: five actions only

## Card hierarchy

- Primary cards: white, 12px radius, clear title and one main action
- Feature cards: equal height in desktop grids
- Course cards: image, metadata, title, benefit summary and actions in fixed order
- App cards: lower visual decoration and denser spacing than public website cards
- Status cards: use color only as an accent, never as the only status indicator

## Page behavior

- Public pages feel like a professional education website.
- Logged-in learning pages feel like a web application.
- Forms remain single-column on phones.
- Tables scroll horizontally and are keyboard focusable.
- Only one FAQ remains open inside each FAQ group.
- Reduced-motion preference disables animated transitions.
