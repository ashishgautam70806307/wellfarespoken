# Phase 175 - Mobile Learning UX

Phase 175 is a mobile-only usability pass based on the approved three-screen mockup. Desktop behavior is intentionally preserved.

## Page mapping

- `spoken-materials.php` -> Spoken Materials / voice-practice entry
- `free-ai-english-practice.php` -> Practice Materials (the project does not contain a `poken-materials.php` file)
- `learning-roadmap.php` -> Learning Roadmap

## Main changes

### Spoken Materials
- Compact mobile page title instead of the large generic hero.
- Search/filter for the four practice modes.
- Four modes become clear two-column touch cards.
- Simple Choose -> Practise -> Improve step strip.
- Once a practice mode starts, the chooser is removed from the active mobile workspace to reduce distraction.
- Voice Coach, Listen, Speak, Check and navigation controls are compact and thumb friendly.
- Previous/Next remains sticky above the mobile bottom navigation.
- Existing Phase 170 continuous voice, auto-next, retry and recovery logic is preserved.

### Practice Materials
- Compact mobile Practice Materials header and four shortcuts: Quick Help, Lessons, Practice and Score.
- Quick Translator/Corrector is hidden by default on mobile and opens only when requested.
- Long lesson lists are replaced on mobile by one searchable native lesson select plus a Start button; desktop lesson cards remain unchanged.
- Selecting a lesson starts it immediately; Start can retry the currently selected lesson.
- Lesson and answer requests use a 12-second browser watchdog so a failed/slow request cannot leave the UI apparently frozen forever.
- Question, answer and result cards are compact; Check Answer is the primary sticky action.
- Previous / Check / Next remain reachable above the bottom navigation.

### Learning Roadmap
- Compact progress-first mobile hero.
- My Progress / All Levels mobile controls.
- Four summary metrics are compact.
- Alternating desktop path becomes a simple vertical mobile timeline.
- Current, completed and locked levels remain visually distinct.
- A current-level Continue action stays above the bottom navigation and follows the real current level generated by existing roadmap logic.

### Common mobile navigation
For these three pages only, the footer uses:

Home -> Materials -> Practice -> Tests -> Roadmap

The current page gets a clear active icon. Existing footer navigation on all other pages is unchanged.

## Fast interaction rules
- Important touch controls are at least 48px high where practical.
- `touch-action: manipulation` is applied to requested learning pages.
- Mobile hover transforms are disabled.
- Tap feedback is immediate and short.
- Page-specific Phase 175 CSS is loaded after compatibility CSS to avoid older phase rules overriding the new mobile layout.

## Compatibility
- No database schema changes.
- No Weekly Test, ranking, security, Materials backend or Roadmap progression rules changed.
- Phase 174 security hardening remains intact.
- Service Worker cache: v175.
