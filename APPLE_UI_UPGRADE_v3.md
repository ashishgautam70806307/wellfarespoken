# BFS Student Portal — Apple-inspired UI Upgrade v3

This version focuses on visual precision rather than changing the approved BFS brand identity.

## Improvements

- System/SF-style typography stack and calmer hierarchy
- Consistent 8px-based spacing rhythm
- Frosted topbar and sidebar surfaces
- Premium sidebar with collapse support on desktop
- Cleaner active menu state and improved navigation alignment
- Redesigned dashboard with balanced hero, metrics, services and daily activity blocks
- Uniform card heights, radius, borders and shadows
- Subtle wave and reveal motion with reduced-motion support
- Attendance page with eligibility-first layout, subject cards, calendar and correction workflow
- Global portal search remains functional and supports Ctrl/Cmd + K
- Existing portal actions remain linked; backend-dependent actions show an interactive process guide
- Light, dark and accent themes preserved
- Responsive desktop, tablet and mobile layouts

## Important boundary

This ZIP is the final static frontend design prototype. Laravel must replace static values with authenticated database data. Financial, attendance, result, document and approval operations must never rely on browser-only state in production.
