# Phase 64 - Spoken Materials Auto Voice Check

Changes:
- Course detail page spacing reduced; same design kept compact.
- spoken-materials.php now supports auto-check:
  - Student clicks Speak & Auto Check.
  - Browser listens in English or Hindi according to practice direction.
  - Transcript appears in answer box.
  - As soon as speech ends, answer is checked automatically.
  - Manual Check button remains only as backup.
- Typing also auto-checks after a small pause.
- Wrong answer returns teacher-style correction and speaks correct sentence.
- Correct answer gives instant praise and repeat guidance.
- Added Listen Correct button in result.

Browser note:
- Voice recognition works best in Chrome/Edge and requires mic permission.
- On HTTPS live server it works more reliably; localhost is also allowed.
