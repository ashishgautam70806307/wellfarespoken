# Phase 66 - Hands-free spoken practice flow

Fixes:
- Hindi to English practice no longer speaks the English answer before student answers.
- System now speaks only the question first.
- After question voice ends, system waits 2 seconds and starts mic automatically.
- Student can practise with headphones and minimum touch.
- After speech ends, answer is checked automatically.
- Correct answer: short voice feedback "Correct. Next." and auto next.
- Wrong answer: only then system speaks the correction.
- Added Hands-free auto mic toggle and Stop Auto button.
