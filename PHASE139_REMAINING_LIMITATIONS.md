# Phase 139 Remaining Limitations

1. The compact one-frame layout is a best-effort mobile UX, not forced clipping. Very long questions, translations, validation messages, the on-screen keyboard, or accessibility text enlargement may still require a short scroll.
2. Browser checks used fixture data. Real persistent registration, admission, Weekly Test, Roadmap and Materials writes must be verified on the user's XAMPP/staging database.
3. Footer network icons appear only when valid URLs are saved in Admin Settings; blank values are intentionally hidden.
4. Phase 139 did not change the database schema or backend business rules.
